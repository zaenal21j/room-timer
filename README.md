# Room Timer

A portable room timer for assessments, training sessions, and OSCE rotations.

## Features

- Free timer mode with configurable alarm repetition count.
- OSCE mode with reading, working, warning, final countdown, and transfer phases.
- Custom announcements, recordings, tones, and countdown styles.
- Indonesian device voices or optional Azure Neural voices.
- Fullscreen participant display with large responsive timer.
- Dark/light display modes and selectable themes.
- Timer state persists across reloads using local storage.
- Offline single-file HTML application.
- Wrapper source folders for desktop and mobile packaging.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Web Speech API
- Web Audio API
- IndexedDB
- Local Storage
- Fullscreen API
- Optional Microsoft Azure Speech REST API
- Electron wrapper source for Windows/macOS
- Capacitor wrapper source for Android/iOS

## Run

Open `Timer-Ruangan.html` directly in a modern browser. No server or installation is required.

For source packaging, see `Timer-Multiplatform/` and `Timer-Multiplatform-Sumber.zip`.
